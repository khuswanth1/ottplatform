# OTT Platform - Frontend

Frontend client for the OTT streaming platform built with React, Vite, Tailwind CSS, and Shaka Player.

## Features
- Movie and TV show browsing with video previews
- Category carousels and billboard banner
- Video player with HLS/DASH streaming support
- User authentication and watchlist management

## Setup & Running

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
